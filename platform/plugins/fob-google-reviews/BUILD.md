# Build Instructions

## Quick Start

```bash
# From project root, build all assets
npm run dev

# Or build for production
npm run prod
```

## Build Process

The plugin uses Laravel Mix (webpack) to compile assets:

### Source Files
- `resources/sass/google-reviews.scss` - SCSS styles
- `resources/js/google-reviews.js` - JavaScript

### Output Files

**Development/Production:**
- `public/vendor/core/plugins/fob-google-reviews/css/google-reviews.css`
- `public/vendor/core/plugins/fob-google-reviews/js/google-reviews.js`

**Production Only (Fallback):**
- `platform/plugins/fob-google-reviews/public/css/google-reviews.css`
- `platform/plugins/fob-google-reviews/public/js/google-reviews.js`

## Build Commands

### Development Build
```bash
npm run dev
```
- Compiles assets
- Generates source maps
- No minification

### Production Build
```bash
npm run prod
```
- Compiles assets
- Minifies CSS and JS
- Removes source maps
- Copies files to `public/` folder for fallback

### Watch Mode
```bash
npm run watch
```
- Watches for file changes
- Auto-compiles on save
- Perfect for development

### Build Specific Plugin
```bash
npm run dev -- --mix-config=platform/plugins/fob-google-reviews/webpack.mix.js
```

## Asset Loading Strategy

The view uses a fallback strategy:

1. **Primary**: Load from `public/vendor/core/plugins/fob-google-reviews/`
   - Generated by webpack build
   - Used in development and production

2. **Fallback**: Load from `platform/plugins/fob-google-reviews/public/`
   - Copied during production build
   - Used if primary path doesn't exist (e.g., fresh install)

## Development Workflow

1. Make changes to SCSS or JS files
2. Run `npm run watch` (or `npm run dev` after each change)
3. Refresh browser to see changes
4. Before deployment, run `npm run prod`

## Troubleshooting

### Assets not loading?

1. Check if files exist:
```bash
ls -la public/vendor/core/plugins/fob-google-reviews/css/
ls -la public/vendor/core/plugins/fob-google-reviews/js/
```

2. If missing, rebuild:
```bash
npm run dev
```

3. Clear cache:
```bash
php artisan cache:clear
php artisan view:clear
```

### Changes not showing?

1. Hard refresh browser (Ctrl+Shift+R or Cmd+Shift+R)
2. Check if watching: `npm run watch` should be running
3. Rebuild: `npm run dev --force`

### Build errors?

1. Check Node version: `node --version` (should be 14+)
2. Reinstall dependencies:
```bash
rm -rf node_modules package-lock.json
npm install
```
